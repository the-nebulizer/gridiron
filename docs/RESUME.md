- **The compile no longer breaks when you act on the advice (2026-09-15)**: `scripts/actions.mjs` used to revalidate every open action as if freshly written, so winning a claim, losing one to a rival, making a recommended lineup swap, or having a trade accepted all made the next routine's compile exit non-zero and publish nothing — worst on the Sunday inactives run, the one with a deadline. It now has two modes: `--check <file>` is strict and is what a routine runs on the report it just wrote; the bare compile computes each action's lifecycle with the same done/gone tests the dashboard uses, carries finished and overtaken actions through with a `state`, exempts them from the sequencing rules, and turns "your open action's drop already left / bid now exceeds FAAB / benched player stopped starting" into a printed note instead of a hard failure. Also enforced now: a `start` must be positionally legal for its slot and must swap in place (a kicker in the QB slot, or a swap that empties another slot, used to validate clean). Both skills and `CLAUDE.md` run `--check` then compile.
- **The free-agent pool is real (2026-09-15)**: `/waivers` drew candidates only from Sleeper's global trending top-100, which in a 12-team league hid most of what is available — 81 of 87 unrostered QBs, including Geno Smith, a listed NFL starter, in a **superflex** league. The snapshot now carries `available`: the actual unrostered pool by position (depth chart 1–2, or trending, or a defense), capped and sorted, ~10KB. Trending entries also stopped calling a drop count `add_count` and now carry `net_adds` — Michael Mayer shows +440k adds against 147k drops, which the old field hid.
- **Publishing is safe on a second run (2026-09-15)**: the skills' publish line lacked `--replace`, so any second publish of the day conflicted on `reports/actions.json` and landed on a fallback branch. All four now pass it. `publish-report.mjs` also recompiles `reports/actions.json` after a `--replace` rebase — it is a derived file, and keeping "ours" over a rebase that brought in another session's report published a card that disagreed with the reports beside it.
